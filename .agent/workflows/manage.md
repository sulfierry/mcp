# Mega-Workflow: MANAGE (System & Orchestration)

Use this workflow to manage the lifecycle of your system, coordinate debugging drops, or handle repository operations.

### How to use:
This is the operations control panel.

**Common Scenarios:**
- "Investigate why the server crashed with a 500 error"
- "Coordinate a deployment to my local staging environment"
- "Analyze all Git commits and generate release notes"
- "Fetch new AI skills from community repositories"

**Agentic Behavior:**
1. Routs to `debugger`, `devops-engineer`, and orchestration protocols.
2. Uses `systematic-debugging` or multi-agent `parallel-dispatching` to solve complex states.
3. Interacts with Git, Docker, and terminal outputs.
