# Mega-Workflow: SCIENCE (Research & Computations)

Use this workflow to perform specialized bioinformatics and hard science computing tasks.

### How to use:
This shifts the AI focus onto empirical data analysis, genome interactions, molecular docking, and high-performance mathematical modeling.

**Common Scenarios:**
- "Run a Molecular Docking analysis on AutoDock Vina"
- "Process and annotate these VCF variants"
- "Evaluate the genetic risk score for this trait"
- "Perform a differential expression analysis for the RNA-seq data"

**Agentic Behavior:**
1. Heavily reliant on local scientific libraries, R scripts, Python bioinformatics suites (Biotite), and MCP external data fetches (ClinVar, PubMed).
2. Summons `bio-orchestrator`, `variant-annotation`, and `molecular-docking` skills.
