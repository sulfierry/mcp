# Mega-Workflow: AUDIT (Security & Compliance)

Use this workflow to unleash red-team investigations and deep architectural scrutiny.

### How to use:
The agent stops building and starts attacking and inspecting. It acts as an adversarial intelligence.

**Common Scenarios:**
- "Perform a static code analysis on my Smart Contracts"
- "Scan this Python script for prompt injection vulnerabilities"
- "Audit my UX against accessibility (WCAG) guidelines"
- "Verify ISO compliance for data handling"

**Agentic Behavior:**
1. Routs to `ai-security-auditor`, `offensive-ai`, and `advanced-code-auditing`.
2. Follows Trail of Bits and Microsoft security methodologies.
3. Recommends remediations without altering live code unless requested.
