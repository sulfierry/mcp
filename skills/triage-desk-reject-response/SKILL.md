# Triage / Desk-Reject Strategy

## What happened

- **Desk-reject**: Editor declines before sending to review. ~50-80% of top-tier submissions.
- **Triage**: Internal editorial board (Nature, Science, NEJM) reviews briefly; 24-72h decision.
- **Under-review desk-reject**: Editor halts review mid-process (rare; usually fast).

Typical rejection reasons (in order):
1. Scope mismatch (most common)
2. Insufficient general interest
3. Insufficient novelty
4. Technical concerns surfaced in skim
5. Competing paper recently accepted
6. Presentation / writing quality

## First 24 hours

Do NOT:
- Reply immediately
- Email editor personally
- Post on social media
- Tell co-authors emotional first reaction is the plan

Do:
- Save editor's exact wording — informs pivot
- Wait 48 hours before any action
- Discuss with senior co-author / mentor

## Appeal decision matrix

Appeal rate success: <5%. Attempt only if:

| Condition | Appeal? |
|-----------|---------|
| Editor misunderstood scope | YES |
| Editor cited wrong reason | YES |
| Editor cited outdated prior work | YES |
| Decision based on review that misunderstood | YES |
| "Insufficient novelty" | NO — subjective |
| "Insufficient interest" | NO — subjective |
| "Fits another journal better" | NO |
| Competing paper accepted | NO |

If appeal, be BRIEF (1 page):
- Restate specific misunderstanding
- Provide evidence (citation, figure)
- Request reconsideration; accept final answer

Example opener:
> "We appreciate your time with our submission [Title]. We write to respectfully note a possible misunderstanding regarding [specific point]. Our findings differ from [prior work] because [concrete evidence]. We ask whether you might reconsider or offer alternative framing."

Never: "our paper is groundbreaking" / "the reviewer is wrong" / "you didn't read the manuscript".

## Cascade / transfer planning

Most publishers offer auto-transfer:

| Flagship | Cascade path |
|----------|-------------|
| Nature | Nat Comm → Sci Rep |
| Science | SciAdv → (end) |
| Cell | Cell Rep → iScience → Heliyon |
| NEJM | No auto cascade; try Lancet, JAMA |
| eLife | No cascade; try PLOS Biology |

Transfer:
- Preserves review reports (if any)
- Saves ~4-8 weeks
- Signals tier downshift to future readers (mild)

Accept if decision is scope/interest, not technical. Decline if technical concerns need addressing first.

## Lateral pivot (different publisher, same tier)

If Nature desk-rejects → don't always go to Nature sister journal. Consider:
- Cell (different publisher, similar tier)
- eLife (open, transparent peer review)
- PNAS (fast, prestigious, broad)

Advantage: fresh editorial eyes. Disadvantage: full resubmission + cover letter rewrite.

## Reformulation for tier-2

If desk-rejected at tier-1 for "insufficient interest":
- Reframe for specialty journal — make methods the hero
- Often: specialty-journal editor values technical depth > broad appeal
- Rewrite abstract + intro to match specialty scope
- Keep figures; rewrite framing

## Learning from editorial feedback

Parse editor's 2-3 sentences CAREFULLY:

| Phrasing | Means |
|----------|-------|
| "while we appreciate the findings..." | Soft decline; findings are OK, venue-fit is issue |
| "would be better suited for..." | Explicit redirect — take seriously |
| "unable to compete for our limited space" | Saying "good but not Nature" |
| "additional data would strengthen..." | Could consider reformulation + experiments + resubmit |
| "conceptually limited" | Novelty critique — needs heavy pivot |
| "previously reported" | Cite the prior work in revision |

Use this to target next submission accurately.

## Timeline after desk-reject

| Week | Action |
|------|--------|
| 0 | Receive decision. Wait. |
| 1 | Discuss with senior author. Read decision + any reviewer notes carefully. |
| 1-2 | Decide: appeal / cascade / lateral / reformulate / tier-down. |
| 2-3 | Modify cover letter + abstract for new target. |
| 3 | Submit to next venue. |

Total gap: ~3 weeks. Don't let manuscript sit >2 months.

## Submission history tracking

Maintain internal log per paper:
```
Title: [working title]
v1 (2025-01-15): Nature — desk-reject ("scope fit")
v2 (2025-02-05): Cell — desk-reject ("competing recent paper")
v3 (2025-03-01): Nature Comm — under review
```

For transparency in CV + track record analysis. Some journals ask for submission history.

## Emotional management

- Desk-rejects at top-tier are the norm, not failure
- High-profile senior scientists have hundreds of desk-rejects across career
- Impostor syndrome trigger — acknowledge, don't amplify
- Fast pivot > dwelling
- Use the paper's bioRxiv preprint DOI to maintain priority while you shop

## When to stop at a tier

Rules of thumb:
- 2 desk-rejects at same tier → drop a tier
- 1 desk-reject + 1 peer-review reject → drop half-tier
- 3 total rejections → reformulate before resubmitting anywhere

Do NOT:
- Shop to 5+ journals without re-examining paper
- Ignore consistent feedback ("lacks novelty" from 3 editors = real)
- Burn bridges (editorial community is small)

## Strategic priority via preprint

If desk-reject stings, the preprint (bioRxiv/arXiv) posted on submission day:
- Establishes priority
- Lets field see work while you pivot
- Citations accumulate pre-publication
- Some funders count preprints toward output metrics

## Anti-patterns

- Resubmitting verbatim to another tier-1 without revision
- Emailing editor to "discuss the decision" (almost always counterproductive)
- Hiding desk-reject from co-authors (transparency matters)
- Posting decision letter publicly (unprofessional)
- Taking >3 months to pivot (paper stales)
- Shopping same paper to 5+ journals sequentially without reformulation
- Treating desk-reject as reviewer feedback (it isn't — editor rarely has time to give substantive critique)
