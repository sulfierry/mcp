# Journal / Venue Selection

## Decision dimensions

1. **Scope fit** (most important)
2. **Audience reach** (who will read?)
3. **Prestige / ranking** (career, but secondary)
4. **Timeline** (pre-submission inquiries, mean time to first decision, acceptance)
5. **Open access policy** (aligned with funder mandates)
6. **Reputation / legitimacy** (anti-predatory)
7. **Transfer network** (cascading rejection within publisher)
8. **Cost** (APCs vs transformative agreements)
9. **Formatting overhead**

Put scope + audience first. Prestige chases scope fit, never reverses.

## Metrics — know limitations

| Metric | Source | Caveat |
|--------|--------|--------|
| **JIF** (Journal Impact Factor) | Clarivate JCR | 2-year window, skewed by high-cite outliers, rewards reviews, not article-level |
| **CiteScore** | Scopus | 4-year window, broader coverage |
| **SNIP** | Scopus | Normalized by field citation rate |
| **SJR** | Scopus | Prestige-weighted citations (PageRank-like) |
| **Eigenfactor / AI (Article Influence)** | EF.org | Like SJR, excludes self-citations |
| **h5-index / h5-median** | Google Scholar | Open, includes prestigious venues GS indexes |
| **Altmetric** | Altmetric.com | Attention (news, social), not quality |
| **CiteScore percentile / JIF quartile (Q1-Q4)** | JCR/Scopus | Field-normalized rank — more interpretable than raw |

Use *several* metrics. Q1 in CiteScore + JIF + SJR = real. Any single-metric brag = suspect.

### DORA principle

San Francisco Declaration on Research Assessment: **do not** evaluate individual papers/researchers using journal-level metrics. Signatory institutions (Wellcome, HHMI, many universities) forbid JIF-based hiring/promotion judgments.

## Indexing checks (legitimacy)

A journal is credible if indexed in:
- **Web of Science (WoS)** Core Collection — SCIE / SSCI / AHCI
- **Scopus** — curated
- **PubMed/MEDLINE** — biomed
- **DOAJ** — open access quality seal

Check via:
- Journal's own page (often exaggerates)
- Scimago Journal & Country Rank (scimagojr.com)
- MIAR (miar.ub.edu)
- Ulrichsweb

## Predatory publisher detection

Warning signs (Think. Check. Submit.):
1. Unsolicited email invitation (spam)
2. Guaranteed fast acceptance, "review in 48h"
3. Opaque APC, fee after submission
4. Editorial board with unrelated fields / fake names
5. Not indexed in WoS/Scopus/PubMed
6. No DOI or non-CrossRef DOI
7. No clear peer-review policy
8. Editor-in-chief uncontactable / ghostwriter
9. Misleading impact factor ("Universal Impact Factor", "Global IF")
10. Website mirrors legitimate journal with small name change

Resources:
- **Beall's List** (archived; now *predatoryreports.org*)
- **Cabell's Predatory Reports** (subscription, librarian access)
- **Think. Check. Submit.** (thinkchecksubmit.org) — 20-point checklist
- **COPE** (Committee on Publication Ethics) membership signals good faith
- **OASPA** (Open Access Scholarly Publishers Association) membership

## Submission strategy matrix

**High-ceiling ambitious**: Nature / Science / Cell family → sub-family specialist → strong specialty → field-broad → OA generalist.

**Example (biology)**:
1. Nature / Science / Cell
2. Nature Comm / Cell Rep / PNAS
3. eLife / PLOS Biology
4. Society journals (EMBO J, Genes & Dev, Mol Cell, ...)
5. Specialty (bioinformatics: Bioinformatics, GB)
6. Generalist OA: Sci Rep, PLOS ONE, iScience

Plan top 3 choices in advance. Note turnaround times:

| Journal | Median days to first decision |
|---------|-------------------------------|
| Nature family | 10-30 (for desk-reject; reviewed: 60-120) |
| PNAS | 30-60 |
| eLife | 20-60 (decision after consult) |
| PLOS ONE | 60-120 |
| Specialty | 30-120 |

## Scope fit test

Before writing cover letter:
1. Read last 3 issues' TOC — does your paper sit naturally?
2. Check "aims and scope" page — specific terms match yours?
3. Find 3 recent papers in journal that cite YOUR field's core papers.
4. If you can't find your type of paper in that journal in last year → wrong fit.

## Transfer networks / cascades

Many publishers auto-offer transfer on rejection (preserves reviews):
- Nature Portfolio: Nature → NatComm → Sci Rep
- Cell Press: Cell → Cell Rep → iScience → Heliyon
- PLOS: any PLOS → PLOS ONE
- Wiley, Elsevier, Springer each have cascades

Transfer saves time (reviews move with you) but signals the review outcome. OK for minor downshifts, not aspirational upshifts.

## Pre-submission inquiry

Some top venues (Nature, Cell, Science, eLife) allow presubmission inquiries. Send:
- Abstract + key figure
- 1-paragraph pitch: why this, why now, why here
- Response in 1-2 weeks tells fit before formal submission.

## Open Access economics

- **APC range** (2024): Nature Communications $6,990; PLOS ONE $1,931; Scientific Reports $2,390; eLife ~$3,000; diamond (Q Open, SciPost) $0.
- Check institutional **transformative agreements** — may cover APC entirely.
- **Green OA**: self-archive preprint + postprint (check Sherpa Romeo for embargo / version allowed).
- **Funder mandates**: NIH 2023+ Data Management and Sharing; Plan S (cOAlition S): CC-BY + immediate OA required; UKRI, Wellcome, ERC similar.

## Conferences vs journals (CS, engineering)

In CS/ML: conferences are primary. Top-tier: NeurIPS, ICML, ICLR, ACL, EMNLP, CVPR, ICCV, SIGGRAPH, STOC, FOCS. Check CORE ranking (A*/A/B/C), CSRankings.

In other fields: conference papers usually secondary to journal.

## Rejection strategy

- ~2 weeks: allow bounce-back emotions. Don't re-submit same day.
- Read reviews honestly. If critique is valid → improve manuscript.
- If desk reject on scope → try next-tier or lateral fit.
- If technical rejection → appeal rarely succeeds (<5%) unless clear reviewer error.
- Cascading transfer requires careful cover letter ("We believe revised manuscript now fits XYZ journal because...").

## Cover letter (top venues)

1 page, 3 paragraphs:
- **Paragraph 1**: What you did + headline finding + why novel.
- **Paragraph 2**: Why it matters (field + broader).
- **Paragraph 3**: Why this journal (scope match, audience, companion papers).

Declare: conflicts, prior submissions, preprint status, suggested + opposed reviewers.

## Institutional considerations

- **MIT/Harvard/Cambridge** tenure/hiring: increasingly DORA-aligned; emphasis on individual paper quality not JIF.
- **Non-Western / teaching-load institutions**: often still use JIF/quartile ranking.
- **Chinese** reforms: pivoting from pure JIF to "representative works".
- **Know your context** — optimize accordingly.

## Anti-patterns

- Targeting high-JIF journal with wrong-scope paper → repeated desk-rejects
- Submitting to "MDPI special issue" solicitation without scope review
- Choosing journal by "acceptance rate" (proxy for predatory)
- Ignoring funder OA mandate → compliance failure
- Submitting to journal on Beall's / Cabell's list
- APC payment BEFORE decision (red flag)
- Same paper simultaneously to multiple journals (duplicate submission)
- Salami-slicing thesis into maximum LPU (least publishable units) — frowned upon
