# Response to Reviewers

## When to use
- Received minor/major revision decision
- Drafting rebuttal + revised manuscript
- Planning new experiments to address reviewer concerns
- Handling conflicting reviewer requests

## Core principles

1. **Respect**: Address every comment. Never say "reviewer misunderstood" outright.
2. **Concede where valid**: Fast concession strengthens credibility.
3. **Push back with evidence**: Disagree only with data/references.
4. **Specific**: Quote exact text + page/line numbers of changes.
5. **Scope-manage**: Some requests are out-of-scope — say so respectfully.

## Revision letter structure

```
Dear [Editor],

Thank you for handling our manuscript [title] and for the reviewers'
constructive feedback. We have carefully addressed all comments. Below
we provide point-by-point responses (reviewer comments in italic, our
responses in plain text, manuscript changes in blue).

## Summary of major changes
1. [Change 1 — 1 sentence]
2. [Change 2]
3. [Change 3]

[Signature]

---

## Reviewer 1

> "R1.1 — [exact quote]"

[Response]

Change: [page X, lines Y-Z; new text or Fig M].

> "R1.2 — ..."
...

## Reviewer 2
...

## Reviewer 3
...
```

## Color coding

- **Black**: original comments (or italics)
- **Blue**: your responses
- **Red (or track changes)**: manuscript text changes
- Consistent palette across the letter

## Response patterns (by comment type)

### Valid critique
*"The sample size is too small to support claim X."*

Response: *"We agree. We have (1) expanded the dataset to N=50 (new Extended Data Fig 4), which reproduces the effect at p < 0.001; (2) softened the claim in the Discussion (page 8, lines 12-15): 'our findings are consistent with X, pending validation in larger cohorts.'"*

→ Concede + act + revise language.

### Reasonable critique, already addressed
*"Have the authors considered confounder Y?"*

Response: *"We appreciate this point. As described in Methods section 'Adjustments' (page 4, lines 3-8), we adjusted for Y in the regression model (Table 2, Model 2). We have clarified this in the Results section (page 5, line 18): 'after adjustment for Y, the effect persists (β = 0.37, 95% CI 0.21-0.53).'"*

→ Redirect to existing content + add clarifying sentence.

### Critique based on misreading
*"The authors claim X causes Y, but show only correlation."*

Response: *"We regret any lack of clarity. Our claim is weaker: we report association, not causation, as we state in the Introduction (p2, l10) and Discussion (p9, l5). We have added a sentence to the Results (p5, l22) to reinforce this: 'These findings are correlational; intervention studies are needed to establish causation.'"*

→ Assume fault for unclarity + reinforce original framing.

### Out-of-scope request
*"The authors should perform experiments in model organism Z."*

Response: *"This is an excellent direction. Experiments in Z would require a 6-12 month effort (breeding, ethics approval). We propose this as an important follow-up study (new Discussion paragraph, p10, l4-9). Our current manuscript's scope — establishing [primary claim] in [current system] — already provides N novel insights. We respectfully suggest the Z experiments warrant separate investigation."*

→ Acknowledge value + justify scope + commit to future work.

### Disagreement with reviewer (rare)
*"The statistical method is inappropriate."*

Response: *"We respectfully disagree. Our choice of [method] follows [standard X in field, ref]. We compared alternatives (new Supplementary Note 2): [method A] yields p = 0.02 and [method B] yields p = 0.03, both significant. We believe [chosen method] is well-justified but have added Supplementary Note 2 for transparency."*

→ Respectful + evidence + give reviewer something (Supp Note) even if you don't change position.

### Conflicting reviewer requests
*"R1 wants more statistical rigor; R2 wants less statistical detail for readability."*

Response letter: *"R1.3 and R2.5 requested opposite changes. We opted to keep detailed statistics in the Methods (R1's direction) while adding a plain-language summary at the start of the Results (R2's direction), yielding a compromise. We welcome the editor's guidance."*

→ Name conflict, explain compromise, defer to editor.

## Major revisions: new experiments strategy

Budget honestly:
- **Can do in 6 weeks**: propose and execute; describe in letter
- **Can do in 3-6 months**: propose but request extended deadline from editor
- **>6 months or infeasible**: explain + offer alternative (literature-based defense, pilot data, pushback)

Include timeline in letter:
*"We propose to complete [experiments] by [date]. If this timeline exceeds journal policy, please advise."*

## Tracking changes

Use MS Word / Overleaf "track changes":
- Upload clean PDF + tracked-changes PDF
- Or a single PDF with color-coded text

Match revised manuscript to letter:
- Letter says "page 8, lines 12-15" → numbers match submitted manuscript
- Use line-numbered PDF (check Overleaf option)

## Tone anti-patterns

- "The reviewer clearly did not read the manuscript" (never)
- "As we stated clearly..." (condescending; use "we recognize the need to clarify")
- "This comment is incorrect" (use evidence, not labels)
- "We strongly disagree" without substantive follow-up
- Sarcasm — even mild
- Making reviewer look foolish — editor dislikes; referee will escalate
- Passive-aggressive "as requested by the reviewer" (condescending)

## Two-round revision pattern

R1 (major revision) → R2 response letter references R1 changes + new concerns:

```
"In response to Reviewer 1's additional concern (R1.1 in this round,
following their R1.3 in the previous round): ..."
```

Maintain continuity. Editors check responses across rounds.

## When reviewer is hostile

- Still respectful
- Quote objectively + respond with evidence
- If personal attack: bring to editor privately, not in public letter
- Track pattern across reviews — consistent hostility from one reviewer can be flagged to editor

## Revision letter length

- Minor revisions: 2-5 pages
- Major revisions: 10-30 pages
- 3 reviewers × 10 points × 1 paragraph each = ~15 pages is normal

Editors prefer thorough over terse.

## Checklist

- [ ] Every reviewer comment addressed (numbered)
- [ ] Page/line references to manuscript changes
- [ ] Quoted comments verbatim
- [ ] Color / italics distinguish comment vs response vs changes
- [ ] Manuscript track-changes + clean versions uploaded
- [ ] New experiments described + data included (fig, stats)
- [ ] Summary of major changes at top
- [ ] Thank editor + reviewers professionally
- [ ] Out-of-scope items justified, not dismissed
- [ ] Response letter does NOT exceed manuscript length
- [ ] No typos / grammar issues
- [ ] Figures renumbered if main figures changed
